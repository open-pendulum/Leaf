# Leaf

[![C++](https://img.shields.io/badge/C++-20-blue.svg)](https://isocpp.org/)
[![CMake](https://img.shields.io/badge/CMake-3.25+-blue.svg)](https://cmake.org/)
[![OpenGL](https://img.shields.io/badge/OpenGL-3.3+-green.svg)](https://www.opengl.org/)

Leaf 是一个基于 [TheCherno/Hazel](https://github.com/TheCherno/Hazel) 项目的 C++2D 游戏引擎练习项目。本项目从 Hazel 项目学习了现代 C++ 游戏引擎的设计理念，但在构建系统和项目结构上进行了优化和改进。

## 🌟 项目特点

### 与 Hazel 的主要差异

| 特性   | Hazel | Leaf                   |
|------|-------|------------------------|
| 构建系统 | Premake | CMake 3.25+            |
| IDE      | Visual Studio | Visual Studio or CLion |
暂时会先基于 Haze 实现，后续会逐步增加自己的东西

## 🛠️ 构建和运行

### 环境要求

- **操作系统**: Windows 10/11 (目前仅支持)
- **编译器**:
  - Visual Studio 2022 (推荐)
- **CMake**: 3.25 或更高版本
- **依赖库**:
  - GLFW (窗口管理)
  - OpenGL 3.3+
  - glad (OpenGL 函数加载)
  - stb_image (图像加载)
  - glm (数学库)

### 构建步骤

1. **克隆项目**
   ```bash
   git clone https://github.com/yourusername/Leaf.git
   cd Leaf
   ```

2. **创建构建目录**
   ```bash
   mkdir build && cd build
   ```

3. **配置项目**
   ```bash
   # Visual Studio 2022
   cmake -G "Visual Studio 17 2022" -A x64 -DCMAKE_BUILD_TYPE=Debug ..
   ```

4. **构建项目**
   ```bash
   cmake --build . --config Debug
   ```

5. **运行示例**
   ```bash
   # Debug 配置
   ./bin/Sandbox.exe
   ```

### ## 📋 开发计划

1. **基于 Hazel 完整实现** - 全面学习并实现 Hazel 的核心功能，优化架构设计
2. **实现 macOS 编译** - 添加 macOS 平台支持，完善跨平台构建系统
3. **支持 Metal 后端和 DX 后端** - 实现 Metal (Apple) 和 DirectX (Windows) 渲染后端
4. **2D 渲染引擎 Shader 特效实现** - 参考 [GPUImage](https://github.com/BradLarson/GPUImage) 项目，实现各种 shader 特效，练习 shader 编程能力
5. **抽象自有图形库后端封装** - 设计并实现自己的后端封装图形库
