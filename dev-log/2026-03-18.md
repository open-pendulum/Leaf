### 核心知识点记录

#### 1. OpenGL 着色器实现

**OpenGLShader 类**：
- 负责编译和链接顶点着色器和片元着色器
- 提供 Bind/Unbind 方法管理着色器状态
- 实现了完整的 uniform 上传方法，支持各种类型：
  - `UploadUniformInt` - 上传整数类型
  - `UploadUniformFloat` - 上传浮点类型
  - `UploadUniformFloat2/3/4` - 上传向量类型
  - `UploadUniformMat3/4` - 上传矩阵类型

**着色器编译流程**：
1. 创建顶点着色器和片元着色器
2. 编译着色器并检查编译错误
3. 创建程序对象并链接着色器
4. 检查链接错误
5. 分离并删除着色器对象

#### 2. Renderer 系统更新

**Renderer::Submit 方法**：
- 绑定指定的着色器
- 上传 ViewProjection 矩阵（相机矩阵）
- 上传模型变换矩阵（每个物体的独立变换）
- 绑定顶点数组并发出绘制命令

**关键代码**：
```cpp
void Renderer::Submit(const std::shared_ptr<Shader> &shader,
                      const std::shared_ptr<VertexArray> &vertexArray,
                      const glm::mat4 &transform) {
    shader->Bind();
    std::dynamic_pointer_cast<OpenGLShader>(shader)->UploadUniformMat4(
        "u_ViewProjection", sSceneData->ViewProjectionMatrix);
    std::dynamic_pointer_cast<OpenGLShader>(shader)->UploadUniformMat4(
        "u_Transform", transform);
    vertexArray->Bind();
    RenderCommand::DrawIndexed(vertexArray);
}
```

#### 3. Uniform 命名规范

**新的命名规范**：
- `u_ViewProjection` - 相机的视图投影矩阵
- `u_Transform` - 物体的模型变换矩阵
- `u_Color` - 物体的颜色

**优势**：
- 命名统一，便于维护
- 前缀 `u_` 清晰标识这是 uniform 变量
- 与 Renderer 代码中的上传名称保持一致

```cpp
Shader *Shader::Create(const std::string &vertexSrc, const std::string &fragmentSrc) {
    switch (Renderer::GetAPI()) {
    case RendererAPI::API::OpenGL:
        return new OpenGLShader(vertexSrc, fragmentSrc);
    default:
        LEAF_CORE_ASSERT(false, "Unknown RendererAPI!");
        return nullptr;
    }
}
```

#### 2. 矩阵变换的应用

**模型变换矩阵**：
- 使用 `glm::translate` 创建平移矩阵
- 使用 `glm::scale` 创建缩放矩阵
- 矩阵乘法顺序：先缩放后平移

**代码示例**：
```cpp
glm::mat4 scale = glm::scale(glm::mat4(1.0f), glm::vec3(0.1f));
for (int y = 0; y < 20; y++) {
    for (int x = 0; x < 20; x++) {
        glm::vec3 pos(x * 0.11f, y * 0.11f, 0.0f);
        glm::mat4 transform = glm::translate(glm::mat4(1.0f), pos) * scale;
        Leaf::Renderer::Submit(mFlatColorShader, mSquareVertexArray, transform);
    }
}
```

### 调试记录与问题解决

**问题**：Renderer::Submit 方法中需要访问 OpenGLShader 的特定方法

**解决方案**：
- 使用 `std::dynamic_pointer_cast` 进行类型转换
- 确保只在 OpenGL 渲染 API 下使用此转换
- 这种设计允许未来扩展其他渲染 API 时不需要修改 Renderer 代码

**代码实现**：
```cpp
std::dynamic_pointer_cast<OpenGLShader>(shader)->UploadUniformMat4(
    "u_ViewProjection", sSceneData->ViewProjectionMatrix);
std::dynamic_pointer_cast<OpenGLShader>(shader)->UploadUniformMat4(
    "u_Transform", transform);
```

**问题**：着色器编译错误处理

**解决方案**：
- 实现了完整的错误检查和日志输出
- 在编译和链接失败时提供详细的错误信息
- 使用断言确保着色器编译成功

**代码实现**：
```cpp
GLint isCompiled = 0;
glGetShaderiv(vertexShader, GL_COMPILE_STATUS, &isCompiled);
if (isCompiled == GL_FALSE) {
    GLint maxLength = 0;
    glGetShaderiv(vertexShader, GL_INFO_LOG_LENGTH, &maxLength);
    std::vector<GLchar> infoLog(maxLength);
    glGetShaderInfoLog(vertexShader, maxLength, &maxLength, &infoLog[0]);
    glDeleteShader(vertexShader);
    LEAF_CORE_ERROR("Vertex shader compilation failure! {0}", infoLog.data());
    LEAF_CORE_ASSERT(false, "Vertex shader compilation failure!");
    return;
}
```
