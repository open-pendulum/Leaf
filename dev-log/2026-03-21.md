### 核心知识点记录

#### 1. 纹理坐标系统

**纹理坐标系**：
- OpenGL纹理坐标系与图片坐标系不同
- 左下角为(0, 0)，右上角为(1, 1)
- 标准化坐标，不依赖纹理实际尺寸

**纹理映射原理**：
```cpp
// 顶点数据：位置 + 纹理坐标
float vertices[5 * 4] = {
    -0.5f, -0.5f, 0.0f, 0.0f, 0.0f,  // 左下：位置 + 纹理坐标(0,0)
    0.5f,  -0.5f, 0.0f, 1.0f, 0.0f,  // 右下：位置 + 纹理坐标(1,0)
    0.5f,  0.5f,  0.0f, 1.0f, 1.0f,  // 右上：位置 + 纹理坐标(1,1)
    -0.5f, 0.5f,  0.0f, 0.0f, 1.0f   // 左上：位置 + 纹理坐标(0,1)
};
```

#### 2. 顶点属性Location分配

**关键修复**：index++的重要性
```cpp
// 错误：缺少index++，所有属性都分配到location 0
for (auto &element : layout) {
    glEnableVertexAttribArray(index);
    glVertexAttribPointer(...);
    // ❌ 缺少 index++;
}

// 正确：递增index，确保每个属性正确分配
for (auto &element : layout) {
    glEnableVertexAttribArray(index);
    glVertexAttribPointer(...);
    index++;  // ✅ 关键修复：递增属性索引
}
```

**影响**：
- 缺少index++会导致所有属性冲突
- 位置和颜色数据错位
- 纹理坐标错误导致显示异常

#### 3. 矩阵变换管线

**渲染管线中的变换**：
```
最终位置 = u_ViewProjection × u_Transform × vec4(a_Position, 1.0)
```

**矩阵作用**：
- `u_ViewProjection`：相机视图投影矩阵（每帧统一）
  - 由OrthographicCamera计算得到
  - 包含相机位置、旋转、投影信息
- `u_Transform`：模型变换矩阵（每个物体独立）
  - 包含物体的平移、旋转、缩放
  - 使用GLM库进行矩阵运算

#### 4. 纹理加载和处理

**stb_image使用要点**：
```cpp
// 启用垂直翻转（图片和OpenGL纹理坐标系不同）
stbi_set_flip_vertically_on_load(1);

// 加载图片
stbi_uc *data = stbi_load(path.c_str(), &width, &height, &channels, 0);

// 设置纹理参数
glTextureParameteri(mRendererID, GL_TEXTURE_MIN_FILTER, GL_LINEAR);
glTextureParameteri(mRendererID, GL_TEXTURE_MAG_FILTER, GL_NEAREST);

// 设置环绕方式
glTextureParameteri(mRendererID, GL_TEXTURE_WRAP_S, GL_REPEAT);
glTextureParameteri(mRendererID, GL_TEXTURE_WRAP_T, GL_REPEAT);
```

#### 5. 着色器设计模式

**工厂模式实现**：
```cpp
Shader* Shader::Create(const std::string& vertexSrc,
                       const std::string& fragmentSrc) {
    switch (Renderer::GetAPI()) {
    case RendererAPI::API::OpenGL:
        return new OpenGLShader(vertexSrc, fragmentSrc);
    default:
        LEAF_CORE_ASSERT(false, "Unknown RendererAPI!");
        return nullptr;
    }
}
```

**优势**：
- 支持多种渲染API扩展
- 客户端代码无需关心具体实现
- 符合开闭原则

### Debug 记录与问题解决

#### 问题1：纹理显示为单一颜色而不是棋盘格

**现象**：
- 左上半部分显示为同一个颜色
- 棋格纹理没有正确交错显示

**原因分析**：
- 顶点属性location分配错误
- OpenGLVertexArray中缺少index++
- 纹理坐标和位置数据冲突

**解决方案**：
1. 修复OpenGLVertexArray.cpp中的index++问题
2. 确保每个顶点属性正确分配到对应location
3. 验证纹理坐标定义正确性

**经验教训**：
- OpenGL中顶点属性必须递增分配location
- 多个属性冲突时，包含多个属性的对象受影响更严重
- 纹理坐标错误会导致整个纹理显示异常

#### 问题2：理解纹理坐标系统

**背景**：
不清楚为什么纹理坐标从(0,0)开始而不是图片的左上角。

**解决方案**：
- 学习OpenGL纹理坐标系：左下角为原点
- 了解stb_image的flip_vertical功能
- 理解UV映射的基本原理
