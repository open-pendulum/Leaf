## 🎯 主要改动

### 1. Renderer2D 系统（新增）

#### 1.1 核心类设计
- **新增文件**: `Renderer2D.h` / `Renderer2D.cpp`
- 提供静态方法接口，无需实例化即可使用
- 内部使用 `Renderer2DStorage` 结构存储渲染数据

#### 1.2 主要接口
```cpp
class Renderer2D {
public:
    static void Init();
    static void Shutdown();
    static void BeginScene(const OrthographicCamera &camera);
    static void EndScene();
    
    // 绘制图元
    static void DrawQuad(const glm::vec2 &position, const glm::vec2 &size, const glm::vec4 &color);
    static void DrawQuad(const glm::vec3 &position, const glm::vec2 &size, const glm::vec4 &color);
};
```

#### 1.3 实现细节
- 内置四边形顶点数组（QuadVertexArray）
- 使用 FlatColorShader 进行纯色渲染
- 支持通过 uniform 上传颜色和变换矩阵

#### 2.2 功能特性

#### 2.3 使用示例
```cpp
void Sandbox2D::OnUpdate(Leaf::Timestep ts) {
    m_CameraController.OnUpdate(ts);
    Leaf::RenderCommand::SetClearColor({ 0.1f, 0.1f, 0.1f, 1 });
    Leaf::RenderCommand::Clear();
    
    Leaf::Renderer2D::BeginScene(m_CameraController.GetCamera());
    Leaf::Renderer2D::DrawQuad({ 0.0f, 0.0f }, { 1.0f, 1.0f }, { 0.8f, 0.2f, 0.3f, 1.0f });
    Leaf::Renderer2D::EndScene();
}
```
