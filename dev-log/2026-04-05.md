## 🔍 问题与解决方案

### 问题：启用深度测试后黑屏

**原因分析：**
- 在 `OpenGLRendererAPI::Init()` 中新增 `glEnable(GL_DEPTH_TEST)` 启用了深度测试
- 但 `Clear()` 方法只清除了颜色缓冲区 `GL_COLOR_BUFFER_BIT`
- 深度缓冲区未清除，初始值为 `1.0`（远裁剪平面）
- 新绘制的 fragment 深度值与 `1.0` 比较，全部深度测试失败，导致黑屏

**解决方案：**
```cpp
void OpenGLRendererAPI::Clear() {
    glClear(GL_COLOR_BUFFER_BIT | GL_DEPTH_BUFFER_BIT);  // 同时清除颜色和深度
}
```

**教训：**
- 启用某个 OpenGL 功能时，要确保相关状态被正确初始化
- 深度测试启用后，需要在每帧清除深度缓冲区
