# 工作记录 - 2026年4月6日

## 📋 今日概述

今天主要进行了代码规范化重构，统一了智能指针类型别名，移除了不必要的 LEAF_API 宏，并完善了渲染系统的生命周期管理。

## 🎯 主要改动

### 1. 智能指针类型统一

#### 1.1 类型别名替换
- **Core.h**: 添加 `#include <memory>` 头文件
- 将 `std::shared_ptr` 统一替换为 `Ref`
- 将 `std::unique_ptr` 统一替换为 `Scope`

#### 1.2 受影响的文件
- **Buffer.h/cpp**: `VertexBuffer::Create` 和 `IndexBuffer::Create` 返回类型改为 `Ref<>`
- **VertexArray.h/cpp**: 成员变量和返回类型改为 `Ref<>`
- **Window.h**: `Window::Create` 返回类型改为 `Scope<Window>`
- **Logger.h/cpp**: logger 成员改为 `Ref<spdlog::logger>`
- **OpenGLVertexArray.h/cpp**: 成员变量改为 `Ref<>`
- **OpenGLRendererAPI.h**: `DrawIndexed` 参数改为 `Ref<>`

### 2. 渲染系统生命周期完善

#### 2.1 Renderer 类增强
- **Renderer.h/cpp**: 新增 `Shutdown()` 静态方法
- 在 `Shutdown()` 中调用 `Renderer2D::Shutdown()`
- `Submit` 方法参数改为 `Ref<>`，使用 Shader 基类接口

#### 2.2 RendererAPI 工厂方法
- **RendererAPI.h/cpp**: 新增 `static Scope<RendererAPI> Create()` 工厂方法
- 根据 API 类型创建对应的实现

#### 2.3 GraphicsContext 工厂方法（新增）
- **GraphicsContext.h/cpp**: 新增文件
- 提供 `static Scope<GraphicsContext> Create(void* window)` 工厂方法
- 根据 RendererAPI 类型创建 OpenGLContext

### 3. Application 生命周期管理

- **Application.cpp**: 析构函数中调用 `Renderer::Shutdown()`
- **Application.h**: `mWindow` 类型改为 `Scope<Window>`

### 4. 代码规范化

#### 4.1 移除 LEAF_API 宏
移除了以下类上的 `LEAF_API` 导出宏：
- Event 类及其子类（WindowResizeEvent, KeyEvent, MouseEvent 等）
- Layer 类

#### 4.2 添加 explicit 关键字
为单参数构造函数添加 `explicit` 防止隐式转换：
- Layer, WindowProps
- KeyEvent 及其子类
- MouseEvent 及其子类

#### 4.3 使用 = default
- LayerStack 构造函数改为 `= default`
- AppTickEvent, AppUpdateEvent, AppRenderEvent 构造函数改为 `= default`

#### 4.4 include 路径统一
- 将 `"glad/glad.h"` 改为 `<glad/glad.h>`
- 将 `"glm/glm.hpp"` 改为 `<glm/glm.hpp>`
- 将 `"spdlog/..."` 改为 `<spdlog/...>`

### 5. EntryPoint 更新
- **EntryPoint.h**: 添加 `#include "Application.h"` 确保完整性

### 工厂方法模式
```cpp
// RendererAPI.cpp
Scope<RendererAPI> RendererAPI::Create() {
    switch (sAPI) {
    case RendererAPI::API::OpenGL:
        return CreateScope<OpenGLRendererAPI>();
    }
}

// GraphicsContext.cpp
Scope<GraphicsContext> GraphicsContext::Create(void *window) {
    switch (Renderer::GetAPI()) {
    case RendererAPI::API::OpenGL:
        return CreateScope<OpenGLContext>(static_cast<GLFWwindow *>(window));
    }
}
```
