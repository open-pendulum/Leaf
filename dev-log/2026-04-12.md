### 3. OpenGL Debug Callback

#### 3.1 OpenGLMessageCallback 函数
- **OpenGLRendererAPI.cpp**: 添加 OpenGL 调试消息回调
- 根据 severity 级别输出不同日志级别

```cpp
void OpenGLMessageCallback(unsigned source, unsigned type, unsigned id,
                           unsigned severity, int length,
                           const char* message, const void* userParam) {
    switch (severity) {
    case GL_DEBUG_SEVERITY_HIGH:         LEAF_CORE_FATAL(message); return;
    case GL_DEBUG_SEVERITY_MEDIUM:       LEAF_CORE_ERROR(message); return;
    case GL_DEBUG_SEVERITY_LOW:          LEAF_CORE_WARN(message); return;
    case GL_DEBUG_SEVERITY_NOTIFICATION: LEAF_CORE_TRACE(message); return;
    }
}
```

#### 3.2 Init() 中启用调试输出
```cpp
glEnable(GL_DEBUG_OUTPUT);
glEnable(GL_DEBUG_OUTPUT_SYNCHRONOUS);
glDebugMessageCallback(OpenGLMessageCallback, nullptr);
glDebugMessageControl(GL_DONT_CARE, GL_DONT_CARE, GL_DEBUG_SEVERITY_NOTIFICATION, 0, NULL, GL_FALSE);
```
